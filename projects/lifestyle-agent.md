# 🌿 Lifestyle Agent using LangChain & FireCrawl
[🔗 View Project on GitHub](https://github.com/abeeha-baig/Lifestyle-coach-agent)

---

### 🧩 Overview
An AI agent designed to improve wellness, productivity, and self-improvement.  
It **scrapes articles** from trusted sources (Medium, Healthline, etc.) using **FireCrawl**, and **summarizes** them with **GPT-4o-mini**.

---

### 🧠 Key Features
- Web scraping from multiple wellness websites  
- GPT-powered summarization for fast reading  
- Category-based topic filtering  
- Built with privacy-safe API handling  

---

### ⚙️ Tech Stack
- Python, Streamlit  
- LangChain, FireCrawl API  
- OpenAI GPT-4o-mini  
- BeautifulSoup (for fallback scraping)

---

### 💡 What I Did
- Developed modular pipeline for scraping + summarization  
- Implemented async processing for faster data collection  
- Created Streamlit UI for interactive browsing  

---

### 🏁 Outcome
Delivered a personal AI assistant that provides quick wellness insights with a single click.
