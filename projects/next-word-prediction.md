# 🔮 Next-Word Prediction using Fine-Tuned GPT-2
[🔗 View Project on GitHub](https://github.com/abeeha-baig/Next-Word-Prediction)

---

### 🧩 Overview
A fine-tuned **GPT-2 model** designed for **next-word prediction** on domain-specific healthcare data.  
The model learns linguistic and contextual patterns to predict the next probable word in medical sentences.

---

### 🧠 Key Features
- Custom fine-tuning of GPT-2 on domain text  
- Tokenization, preprocessing, and model optimization  
- Real-time inference via Flask API  

---

### ⚙️ Tech Stack
- Python, PyTorch  
- Transformers (Hugging Face)  
- Flask API  
- GPU training (Colab)

---

### 💡 What I Did
- Collected and preprocessed healthcare text  
- Fine-tuned GPT-2 with learning rate scheduling  
- Evaluated perplexity and model coherence  

---

### 🏁 Outcome
Produced a robust domain-specific next-word predictor with improved contextual fluency.
