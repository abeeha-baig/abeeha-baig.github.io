# 🧱 RAG-Based Chatbot for Oracle Database Security (RAG-ODS)
[🔗 View Project on GitHub](https://github.com/abeeha-baig/RAG-ODS)

---

### 🧩 Overview
A **Retrieval-Augmented Generation (RAG)** system for answering questions about Oracle Database security.  
It retrieves relevant text chunks from embedded documents and uses **LangChain** + **LLMs** to generate coherent answers.

---

### 🧠 Key Features
- Vector-based document retrieval  
- Contextual generation with document citations  
- Streamlit interface for real-time interaction  
- Modular RAG architecture (basic, advanced, HyDE-based)

---

### ⚙️ Tech Stack
- Python, LangChain  
- FAISS / Chroma for vector storage  
- OpenAI & Gemini LLMs  
- Streamlit UI

---

### 💡 What I Did
- Designed ingestion & retrieval pipeline  
- Integrated reranking + HyDE techniques for accuracy  
- Tuned prompt templates for factual precision  

---

### 🏁 Outcome
Achieved **~93% relevance accuracy** in Oracle DB security question answering, improving documentation accessibility for users.
