# 💰 Financial Data Bot using LangChain’s Pandas Agent
[🔗 View Project on GitHub](https://github.com/abeeha-baig/financial-chatbot)

---

### 🧩 Overview
An intelligent chatbot that enables users to interact with **CSV-based financial datasets** through **natural language queries**.  
It uses **LangChain’s Pandas Agent** with OpenAI’s API to process questions like  
> “Show me all transactions greater than $10,000 in Q2.”

and returns data tables with precise answers.

---

### 🧠 Key Features
- Natural Language interaction with tabular financial data  
- Uses **LangChain’s Pandas Agent** to parse and execute data queries  
- Summarizes and interprets dataset insights  
- Deployed via **Streamlit** for a smooth UI  

---

### ⚙️ Tech Stack
- Python, LangChain, Pandas Agent  
- OpenAI API  
- Streamlit  
- Flask (for API integration)

---

### 💡 What I Did
- Designed the query-processing logic  
- Built prompt templates for structured data interpretation  
- Integrated LLM outputs with Pandas operations  
- Optimized performance for large CSVs

---

### 🏁 Outcome
Reduced manual filtering of financial data by **80%** and provided explainable insights directly via chat.
